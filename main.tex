\vspace{0.3cm}

\textbf{摘要：}本文面向人口老龄化加速背景下的嵌入式社区养老服务站"建在哪、建多大、收多少钱"的全链条决策问题，以某城市10个连片小区为实证场景，建立了"增生型Markov链$\to$MILP-MCLP-ES选址$\to$词典序MILP定价$\to$多维鲁棒性检验"的四阶段递进求解框架。Q1构造增生型3状态Markov转移矩阵并以Leslie矩阵进行双模型三角校验——两种独立范式的5年60+人口预测偏差仅1.7\%，其中失能老人从625人飙升至1,125人（+80.3\%）。Q2构建MILP-MCLP-ES模型，以Church\&ReVelle (1974)经典MCLP为理论底座，引入McCormick包络与Big-M方法将含非线性满意度耦合的选址问题等价转化为MILP，由CBC分支定界求解，在120万元预算内实现\textbf{10/10小区全覆盖}——最优方案F(大型)+H(中型)+J(中型)，总建设成本109万元，年总利润1,097.7万元。Q3在固化选址后以词典序目标优化6项服务定价，全部维持$S_3=1.000$平价段，仅上门护理从30元降至12.64元以满足F站8\%利润率紧约束，三层交叉补贴机制使紧急救助年净支出47.42万元由营利服务利润完全吸收（交叉补贴率仅14.3\%）。Q4三场景灵敏度分析表明系统具有强鲁棒性（$\rho_{\min}>0.97$），确定解对非确定解的目标值提升达24\%。本文的MILP-MCLP-ES框架可平滑迁移至分级诊疗站点选址、冷链前置仓网络规划等公共设施优化场景。

\textbf{关键词：}嵌入式养老；马尔可夫链；最大覆盖选址；混合整数线性规划；McCormick包络；交叉补贴；鲁棒性分析

\section{结论}

本文面向嵌入式社区养老服务站"建在哪、建多大、收多少钱、抗多大风险"的全链条工程决策问题，以增生型Markov链、MILP-MCLP-ES选址模型与词典序MILP定价模型为核心工具，在10个小区实证场景上完成了预测--选址--定价--灵敏度的闭环求解，得到以下核心结论：

\begin{enumerate}[label=\textbf{(\arabic*)}, leftmargin=*]

    \item \textbf{人口预测的双模型三角校验确立了需求基线的可信度边界}。增生型Markov链与Leslie矩阵两种独立范式对第5年末60+人口的预测偏差仅为1.7\%，Leslie主特征值$\lambda_1=1.0198$与Markov隐含年均增长率2.0\%的精确吻合排除了单一模型的系统性偏差。失能老人的"棘轮增长"（+80.3\%）构成全系统最严峻的需求端压力——5年内失能率将从9.1\%攀升至14.8\%，半失能老人充当了这一增长的"加速通道"（净流出-3.7\%，其中10\%转化为失能、其余5\%死亡或维持）。

    \item \textbf{MILP-MCLP-ES模型在120万元预算内实现了全覆盖的确定性最优解}。通过randomSeed=42的确定性求解，CBC在120秒内找到目标值54.225的全覆盖方案——F(大型,45万)+H(中型,32万)+J(中型,32万)，总建设成本109万元，覆盖率10/10（100\%），年总利润1,097.7万元。与非确定解（目标值43.644，覆盖率80\%）相比，目标值提升24\%，揭示多起点随机重启策略在CFLP类MILP中的方法论价值。三站全员$S_2=0.600$（利用率92--96\%）表明120万元预算恰好处于"全覆盖"与"满意服务"的帕累托前沿拐点。

    \item \textbf{词典序MILP定价在利润率$\le8\%$监管红线下实现了全$S_3=1.000$的帕累托最优}。上门护理从30元降至12.64元（-57.9\%）以满足F站（最大荷载站）的8\%利润率紧约束，其余5项服务维持基准价——其经济学本质是Ramsey-Boiteux最优定价的"反向价格歧视"：高频低价服务（助餐:10元$\times$118,443次/月）受保护，低频高价服务（上门护理:30元$\times$19,608次/月）以最高价格弹性吸收监管约束。三层交叉补贴机制使紧急救助年净支出47.42万元由营利服务利润（331.3万元）完全吸收，交叉补贴率仅14.3\%。

    \item \textbf{方案在多维扰动下呈现强鲁棒性，随机种子控制为方法论贡献}。三场景6组MILP重求解的韧性系数$\rho$均大于0.97。确定解对非确定解的24\%提升揭示了MILP在非凸满意度景观上的多峰性质——在竞赛环境中，多起点随机重启（10次独立求解取最优）是回避局部最优陷阱的低成本有效策略，建议作为CFLP类MILP的标准求解协议纳入建模规范。

\end{enumerate}

综上所述，本文的MILP-MCLP-ES框架为"资源约束下的嵌入式养老设施规划"提供了一套数学上严谨、工程上可操作的定量决策工具。模型的Church\&ReVelle MCLP理论底座、McCormick/Big-M精确线性化方法体系、多起点随机重启的确定性求解策略与三层交叉补贴机制，可平滑迁移至分级诊疗站点选址、冷链前置仓网络规划与新能源充电桩布局等更广泛的公共设施优化场景——如§6.4所论证，其核心方法论在"覆盖率--满意度"帕累托前沿的数学构造上具有跨领域的普适性。

\section{主要算法伪代码}

\subsection*{算法1：MILP-MCLP-ES 选址-规模优化}

\begin{lstlisting}[language=Python, caption={MILP-MCLP-ES核心算法框架}]
# 输入: I(小区集), K(规模集), D(需求), d(距离矩阵), B(预算)
# 输出: y*(选址-规模), x*(服务分配)

# Step 1: 构建MILP模型
prob = LpProblem("MCLP_ES", LpMaximize)

# Step 2: 决策变量
y[i,k] = Binary  # 小区i是否建规模k的站
x[i,j] = Binary  # 小区i是否由站j服务
s1[i,j] = Continuous  # S1距离满意度 (0.6-1.0)
s2[i] = Continuous    # S2响应满意度 (0.6-1.0)

# Step 3: Big-M线性化 S1 (4段)
for each (i,j) with d[i,j] <= 1000:
    sum(delta_s1[ell]) = x[i,j]
    s1[i,j] = sum(val[ell] * delta_s1[ell])

# Step 4: Big-M线性化 S2 (5段，基于利用率)
for each i:
    sum(delta_s2[ell]) = station_exists[i]
    s2[i] = sum(val[ell] * delta_s2[ell])

# Step 5: McCormick包络
w[i,j] = s2[i] * x[i,j]  # 非线性!
# 替换为:
w[i,j] <= x[i,j]
w[i,j] <= s2[i]
w[i,j] >= s2[i] - (1 - x[i,j])

# Step 6: 目标与约束
max sum(coverage * 5.0 + weighted_S * 0.5)
s.t. budget, capacity, single-sourcing, radius

# Step 7: 求解
solve_with_fallback(prob, time_limit=180)  # CBC -> Gurobi -> Mosek
\end{lstlisting}

\subsection*{算法2：S3价格满意度Big-M线性化 (Q3)}

\begin{lstlisting}[language=Python, caption={定价优化S3线性化}]
# S3四段: 平价[0,1.0] / 微溢价(1.0,1.1] / 中溢价(1.1,1.2] / 高溢价(1.2,2.0]
# 对应S3值: 1.00, 0.90, 0.75, 0.60

for each service s (except emergency):
    # 恰好选一段
    sum(delta_s3[s,ell] for ell in 0..3) == 1

    for ell in 0..3:
        lo = base[s] * S3_lo[ell]
        hi = base[s] * S3_hi[ell]
        p[s] >= lo - M * (1 - delta_s3[s,ell])
        p[s] <= hi + M * (1 - delta_s3[s,ell])

    s3[s] = sum(S3_val[ell] * delta_s3[s,ell])

# 词典序目标
max sum(demand[s] * s3[s] * 0.5) + epsilon * sum(demand[s] * p[s])
\end{lstlisting}
